# Security Policy

## Supported Versions

Security fixes are applied to the latest major release. Older majors may receive a narrowly scoped fix when it can be made safely, but they are not guaranteed to track the evolving Web Bot Auth Internet-Draft.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities privately via GitHub Security Advisories for this repository.
Include a clear description, reproduction steps, and potential impact.

We will acknowledge receipt and provide updates as we triage and remediate.
